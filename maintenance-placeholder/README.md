# Временная заглушка zrenie.clinic

Для переноса нужен **только `index.html`** из этой папки. Стили, фирменный
логотип и шрифты встроены в HTML; внешних запросов, JavaScript, PHP, Laravel
и подключения к базе данных нет. Файл можно открыть прямо в браузере.

1. Добавьте домен `zrenie.clinic` на резервном сервере и загрузите `index.html`
   в корневую папку этого домена. Убедитесь, что сервер открывает именно этот
   файл как стартовую страницу (другой `index.php` может иметь приоритет).
2. Настройте HTTPS-сертификат для `zrenie.clinic` и, если используется,
   `www.zrenie.clinic`: перенос одного HTML не переносит сертификат.
3. Направьте DNS домена на резервный сервер. Проверьте записи A и AAAA,
   а также `www`, если он используется: они должны вести на нужный сервер.
4. Проверьте открытие `https://zrenie.clinic` с компьютера и телефона.

Если заглушка должна показываться также по старым адресам страниц
(например, `/kirov/services/...`), настройте на резервном сервере обработку
любого пути этим HTML. Для временной недоступности желательно возвращать
HTTP-статус **503 Service Unavailable** с заголовком **Retry-After: 3600**.
Статус и заголовки задаются сервером; один статический HTML их не устанавливает.
Точная настройка зависит от сервера (Nginx, Apache или панель хостинга).

После восстановления основного сервера верните DNS на прежние адреса.
Этот каталог не подключён к маршрутам Laravel и сам по себе не заменяет
главную страницу рабочего приложения.
