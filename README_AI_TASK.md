# README_AI_TASK

Эта инструкция предназначена для AI-исполнителя внутри данного репозитория.

## Перед началом любой задачи
- Прочитать `AGENTS.md`.
- Не читать `docs/APP_CONTEXT.md` по умолчанию.
- Читать `docs/APP_CONTEXT.md` только по прямой просьбе пользователя, например: «Изучи документ `docs/APP_CONTEXT.md`, тему ...».
- Если задача относится к конкретному модулю, открыть связанный документ из `docs/*`, кроме `docs/APP_CONTEXT.md`, если пользователь не попросил его явно.

## Что это за проект
- Медицинский сайт клиники.
- Основной стек: `Laravel 10 + Blade + Vue 2.7 + Vite + TailwindCSS`.
- Админка: `Filament 3`.
- Есть мультигород, контентные страницы, врачи, услуги, отзывы, профиль пользователя, формы записи и callback, интеграция с UNF API, генерация sitemap и YML-фида.

## Правила работы
- Ничего не выдумывать о проекте: опираться только на код, конфиги, миграции и существующие документы.
- Сначала искать уже существующую реализацию, а потом менять её.
- Учитывать мультигород в маршрутах, URL, меню, кешах, выборках и SEO.
- Не ломать внешний контракт текущих маршрутов и интеграций без явного запроса.
- Не обновлять `docs/APP_CONTEXT.md` автоматически после правок. Обновлять его только по прямой просьбе пользователя.

## Экономия контекста и токенов
- По умолчанию читать только целевые файлы и ближайший связанный код.
- Не выводить большие `diff`, логи, дампы или документы в чат без прямой просьбы пользователя.
- Для логов и ошибок читать только релевантный фрагмент, обычно последние 30–50 строк или строки вокруг ошибки.
- Использовать `rg`/точечный `sed` вместо чтения больших файлов целиком.
- Запускать тесты точечно через `--filter`, если задача не требует полного test-suite.
- Не запускать `npm run build`, если правка backend-only и сборка frontend не нужна для проверки.
- Не делать browser-smoke, SSH-проверки и внешние проверки без необходимости или прямой просьбы.
- Не смешивать несколько независимых тем в одну диагностику; держать фокус на текущей задаче.

## Особенности проекта, которые нельзя игнорировать
- `SetCityMiddleware` влияет на URL, cookies, auto-detect города и глобальные пути.
- Модели с `HasCityScope` автоматически фильтруются по текущему городу.
- Есть два источника цен:
  - актуальная структура услуг и цен в БД через `ServicePriceService`;
  - legacy-интеграция через `Clinic::prices()` и `PriceService`.
- Внешние формы и часть API завязаны на UNF (`config/zrenie-clinic.php`).
- Админка использует guard `staff`.
