## 🎯 Задача

Создать новую форму онлайн-записи, которая:
- Интегрируется с API adminzrenie.ru для получения данных врачей и расписания
- Поддерживает работу с несколькими городами
- Решает проблему медленной загрузки старой формы
- Предотвращает овербукинг через проверку слотов

## ✅ Выполненная работа

### 1. Создана архитектура компонентов

#### Главный компонент: `BookingWidgetV2.vue`
- Управляет всем процессом записи
- Переключает между шагами
- Хранит состояние формы
- Взаимодействует с API

#### Компоненты шагов (5 шт.):
1. **DoctorSelectionStep.vue** - выбор врача из списка
2. **DateSelectionStep.vue** - выбор даты через календарь
3. **TimeSelectionStep.vue** - выбор времени из доступных слотов
4. **PatientFormStep.vue** - ввод данных пациента
5. **ConfirmationStep.vue** - подтверждение успешной записи

### 2. Создан API сервис

**Файл**: `resources/js/services/bookingApi.js`

**Функционал**:
- Централизованная работа с API
- Автоматическое переключение dev/prod endpoints
- Обработка ошибок
- Timeout 30 секунд
- Логирование запросов

**Методы**:
```javascript
getCities()                     // Список городов
getDoctorsByCity(cityId)        // Врачи по городу
getDoctorSlots(doctorId, date)  // Слоты врача
checkSlot(slotData)             // Проверка доступности
createApplication(data)          // Создание заявки
```

## 🔗 API Endpoints

Используются следующие endpoints из `adminzrenie.ru/api/v1/`:

### Для разработки (тестовый):
```
https://app.fondzrenie.ru/api/v1/
```

### Для production:
```
https://adminzrenie.ru/api/v1/
```

### Список endpoints:
| Method | Endpoint | Описание |
|--------|----------|----------|
| GET | `/cities` | Список городов |
| GET | `/cities/{id}/doctors` | Врачи по городу |
| GET | `/doctors/{id}/slots?date=YYYY-MM-DD` | Слоты врача |
| POST | `/applications/check-slot` | Проверка слота |
| POST | `/applications` | Создание заявки |
