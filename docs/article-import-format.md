# Формат статьи для импорта

Основной сценарий:
- в админке блога вставляется ссылка на Google Docs;
- импортёр читает документ и собирает черновик статьи из блоков.
- при необходимости в форме импорта включается блок «Мнение эксперта», выбирается врач, вводится текст и загружается отдельное фото врача.

Чтобы импорт работал стабильно, документ должен быть оформлен так:

1. Заголовок статьи: стиль `Heading 1`
2. Метаданные перед первым блоком:
   - `Тема: ...`
   - `Теги: тег 1, тег 2, тег 3`
   - `SEO Title: ...` (необязательно)
   - `SEO Description: ...` (необязательно)
3. Каждый блок статьи: стиль `Heading 2`
4. Текст блока: обычные абзацы и списки под своим `Heading 2`
5. FAQ:
   - секция `Heading 2` с названием `FAQ` или `Часто задаваемые вопросы`
   - каждый вопрос внутри нее: стиль `Heading 3`
   - ответ: абзацы и списки под соответствующим `Heading 3`

После импорта блоки статьи располагаются в следующем порядке:

1. Автор и тема
2. Теги
3. Текстовые блоки
4. Мнение эксперта, если оно включено в форме импорта
5. Навигация по статьям
6. FAQ, если он есть
7. Стандартные нижние блоки

Блок навигации добавляется автоматически и не дублируется, если он уже существует.
Фото для блока «Мнение эксперта» используется только в этом блоке и не заменяет фотографию в профиле врача.

Пример:

```text
Heading 1: Что такое мультифокальные линзы

Тема: Очки, Линзы
Теги: очки, линзы
SEO Title: Что такое мультифокальные линзы
SEO Description: Краткое описание статьи

Heading 2: Что такое мультифокальные линзы
Абзац 1
Абзац 2

Heading 2: Виды мультифокальных линз
Абзац 1
Список

Heading 2: FAQ
Heading 3: Кому подходят мультифокальные линзы?
Ответ на вопрос
```

Ограничения текущей версии:
- ссылка должна быть доступна по ссылке без авторизации Google;
- изображения внутри Google Docs пока не прикрепляются к блокам автоматически;
- текст и фото блока «Мнение эксперта» заполняются в форме импорта, а не в Google Docs;
- если нужен резервный режим, можно вставить тот же контент вручную в структурированном виде через поле текста в админке.
