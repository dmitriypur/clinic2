# 🧪 Инструкция по тестированию BookingWidgetV2

## Быстрый старт

### 1. Запуск dev-сервера

```bash
npm run dev
```

### 2. Открытие тестовой страницы

Откройте в браузере:
```
http://localhost/booking-widget-v2-demo
```

или если у вас MAMP:
```
http://localhost:8888/booking-widget-v2-demo
```

### 4. Проверка API запросов

Откройте DevTools → Network и проверьте:

#### Получение врачей
```
GET https://adminzrenie.ru/api/v1/cities/1/doctors
Status: 200
```

#### Получение слотов
```
GET https://adminzrenie.ru/api/v1/doctors/{id}/slots?date=2024-01-15
Status: 200
```

#### Создание заявки
```
POST https://adminzrenie.ru/api/v1/applications
Status: 200 или 201
```

## Проверка ошибок

### Тест 1: Нет врачей
- Измените city_id на несуществующий
- Должно показаться сообщение об ошибке
- Кнопка "Попробовать снова" должна работать

### Тест 2: Нет слотов
- Выберите дату далеко в будущем
- Должно показаться "На выбранную дату нет доступных слотов"

### Тест 3: Валидация формы
- Попробуйте отправить пустую форму
- Должны появиться ошибки валидации
- Попробуйте некорректный телефон
- Попробуйте не согласиться с политикой

### Тест 4: Сетевая ошибка
- Отключите интернет
- Попробуйте открыть виджет
- Должна показаться ошибка "Нет связи с сервером"

## Известные ограничения

1. **Тестовый API**: Данные могут быть тестовыми/неактуальными
2. **Отправка в 1С**: В тестовом окружении может не работать
3. **Метрики**: Работают только при наличии настроенной YM

## Что делать при ошибках

### Ошибка: "Не удалось загрузить список врачей"
1. Проверьте доступность API
2. Проверьте консоль браузера
3. Проверьте Network tab

### Ошибка: "Произошла ошибка при создании заявки"
1. Проверьте заполнение всех полей
2. Проверьте формат данных (телефон, дата)
3. Проверьте консоль на наличие ошибок валидации

### Виджет не открывается
1. Проверьте что `npm run dev` запущен
2. Проверьте консоль на ошибки JS
3. Убедитесь что компонент зарегистрирован в app.js
