# AGENTS.md

Этот файл задаёт постоянные инструкции для ассистента в данном репозитории.

## Порядок работы
1. Сначала прочитать этот `AGENTS.md`.
2. Затем прочитать `README_AI_TASK.md`.
3. Затем прочитать `docs/APP_CONTEXT.md`.
4. При необходимости открыть связанные документы из `docs/*`.

## Режим работы
- Писать кратко и по делу.
- Если задача понятна из кода и конфигурации, не задавать лишних вопросов.
- Не пересказывать большие куски кода в чате без необходимости.
- После изменений давать короткий отчёт: что сделано и в каких файлах.
- После любых изменений в поведении, архитектуре, маршрутах, интеграциях, env или админке обновлять `docs/APP_CONTEXT.md`.

## Технический контекст проекта
- Backend: `Laravel 10`.
- Frontend: `Blade + Vue 2.7 + Vite + TailwindCSS`.
- Admin: `Filament 3` + `Filament Shield` + `Filament Navigation`.
- Основной сайт поддерживает мультигород через URL-префикс и cookies.
- Есть внешняя интеграция с UNF API и отдельное integration API для услуг.

## Ограничения
- Не менять стек без явной задачи.
- Не переписывать проект на Inertia, Vue 3, React или другой frontend-стек.
- Не ломать существующую мультигород-логику, кеши и привязки контента к городам.
- Не удалять существующие документы в `docs/`, если задача не требует консолидации.

## Живой контекст проекта
- `docs/APP_CONTEXT.md` — основной актуальный контекст проекта.
- При обновлении минимум проверить и при необходимости исправить:
  - `Что изменилось (последнее)`
  - `Журнал изменений`
  - `Маршруты`
  - `Сервисы и интеграции`
  - `Env и конфигурация`
  - `Ограничения и замечания`
