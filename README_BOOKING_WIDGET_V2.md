## 🎯 Что это?

**BookingWidgetV2** — это новое поколение виджета онлайн-записи на прием к врачу, которое решает ключевые проблемы старой версии:

### Проблемы старого виджета ❌
- Медленная загрузка (прямые запросы к 1С)
- Нет поддержки нескольких городов
- Риск двойной записи (овербукинг)
- Устаревший UX

### Решения в новом виджете ✅
- ⚡ **Мгновенная загрузка** - данные кешируются на промежуточном API
- 🌍 **Мультигород** - работа с несколькими городами
- 🛡️ **Надежность** - проверка доступности слотов перед записью
- 🎨 **Современный UX** - пошаговый процесс с визуальной обратной связью
- 📱 **Адаптивность** - корректная работа на всех устройствах

## ✨ Особенности

### 🎨 Пользовательский интерфейс

- **Пошаговый процесс** (5 шагов):
  1. Выбор врача
  2. Выбор даты
  3. Выбор времени
  4. Заполнение данных пациента
  5. Подтверждение записи

- **Визуальная обратная связь**:
  - Лоадеры при загрузке данных
  - Понятные сообщения об ошибках
  - Индикация выбранных элементов
  - Навигация вперед/назад

### 🔧 Технические возможности

- **Валидация**:
  - Клиентская валидация форм
  - Маска телефона (+7 (999) 999-99-99)
  - Проверка возраста пациента
  - Обработка ошибок API

- **Производительность**:
  - Lazy loading компонентов
  - Кеширование на стороне API
  - Оптимизация рендеринга
  - Timeout для HTTP запросов

- **Безопасность**:
  - Нет хардкода credentials
  - HTTPS для всех запросов
  - Санитизация ввода
  - Проверка слотов перед записью

### 📡 API Интеграция

Виджет использует endpoints из `adminzrenie.ru/api/v1/`:

```
GET  /cities/{id}/doctors          - Врачи по городу
GET  /doctors/{id}/slots            - Расписание врача
POST /applications/check-slot       - Проверка слота
POST /applications                  - Создание заявки
```

**Тестовый API**: `https://app.fondzrenie.ru/api/v1/`  
**Production API**: `https://adminzrenie.ru/api/v1/`

## ❓ FAQ

### Как открыть виджет программно?

```javascript
// В Vue компоненте
this.$root.bookingWidgetV2Active = true;

// Через eventBus (если настроен)
eventBus.$emit('open-booking-widget');
```

### Как передать ID города?

```blade
<booking-widget-v2
    :city-id="{{ $city->id }}"
    ...
/>
```

### Как переключить API на production?

В `.env`:
```env
VITE_BOOKING_API_URL=https://adminzrenie.ru/api/v1
```

Или изменить в `bookingApi.js`:
```javascript
this.baseURL = 'https://adminzrenie.ru/api/v1';
```

### Где хранятся данные формы?

Данные хранятся локально в компоненте `BookingWidgetV2` и отправляются только при финальной отправке формы.

### Как добавить новый шаг?

1. Создайте компонент в `components/BookingWidgetV2/components/`
2. Зарегистрируйте в `BookingWidgetV2.vue`
3. Добавьте логику переключения

Подробнее в [BOOKING_WIDGET_V2_README.md](./docs/BOOKING_WIDGET_V2_README.md#добавление-нового-шага)

### Как обработать ошибку API?

Все ошибки обрабатываются автоматически в `bookingApi.js`. Для кастомной обработки:

```javascript
try {
  await bookingApi.createApplication(data);
} catch (error) {
  if (error.status === 422) {
    // Ошибки валидации
    console.log(error.errors);
  } else {
    // Другие ошибки
    console.log(error.message);
  }
}
```
